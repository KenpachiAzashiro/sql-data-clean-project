# sql-data-clean-project
Data Cleaning project using my sql
SQL Data Cleaning Project

Project Overview

This project focuses on cleaning and preparing a real-world dataset containing 23,000+ records using MySQL Workbench.

Tasks Performed

- Removed duplicate records
- Standardized inconsistent data
- Handled missing values
- Filled missing industry values using self joins
- Cleaned and formatted date columns
- Removed unnecessary data

SQL Concepts Used

- Joins
- CTEs
- Window Functions
- CASE Statements
- String Functions
- Subqueries

Tools Used

- SQL
- MySQL Workbench
